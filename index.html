AegisKube-SecOps

    

An open-source security sentinel for Linux hosts and Kubernetes nodes. It reports what is misconfigured, spots attack patterns in auth logs, and records every finding in a hash-chained ledger.

    
          
  • Hardening audit. Read-only checks of kernel sysctl settings, SSH configuration, listening ports and known rootkit traces.
    •       
  • Threat detection. Regex signatures, a sliding-window frequency count for brute force, and Z-score checks on network metrics. Rule-based, not a trained model.
    •       
  • Tamper-evident ledger. SHA-256 hash chain with proof-of-work and a verify command that reports the first broken block.
    •     
    

Python 3.10+ / GitHub Actions / Docker / Apache-2.0

    

Next: file integrity monitoring, a SUID scanner, ML-based anomaly detection and a verified Kubernetes DaemonSet deployment. The roadmap in the README marks what is done and what is not.
